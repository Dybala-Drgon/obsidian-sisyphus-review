# Obsidian Sisyphus Review 插件

> 本插件由 Trae AI 生成


## 功能介绍

Sisyphus Review 是一款 Obsidian 插件，能够通过调用 DeepSeek AI 接口分析用户的结构化日记内容，并以法国哲学家阿尔贝·加缪（Albert Camus）的哲学视角提供深度反馈。

该插件将用户的日常琐事与加缪的"荒谬哲学"相结合，引导用户将生活中的挑战升华为"对荒谬的反抗"，支持两种核心使用场景：

- **单日复盘**：分析当前日期的日记内容
- **周度总结**：分析本周的总结内容，并关联整合本周内的相关日记

## 安装方法

### 手动安装

1. 下载最新版本的插件 zip 文件
2. 解压到 Obsidian 的插件目录 (`VaultFolder/.obsidian/plugins/`)
3. 重启 Obsidian
4. 在设置中启用插件
5. 配置 DeepSeek API Key

### 使用 BRAT 安装（推荐）

1. 安装 BRAT 插件
2. 打开 BRAT 设置
3. 在"Add Beta Plugin"中输入插件仓库地址
4. 点击"Add Plugin"
5. 重启 Obsidian
6. 在设置中启用插件
7. 配置 DeepSeek API Key

## 配置说明

在 Obsidian 设置面板中找到 "Sisyphus Review" 设置项：

- **API Key**：输入你的 DeepSeek API Key（必填）
- **API Base URL**：DeepSeek API 地址（默认：https://api.deepseek.com/v1/chat/completions）
- **系统提示词**：引导 AI 扮演加缪角色的提示词（可自定义）
- **高级选项**：
  - 请求超时：API 请求超时时间（默认：30000ms）
  - 重试次数：API 请求失败后重试次数（默认：3次）

## 使用方法

1. 在 Obsidian 左侧 Ribbon 工具栏中点击巨石图标
2. 选择需要的模式：
   - **审视今日反抗**：处理当前光标所在位置的日记内容，或自动识别并处理当前日期（格式为 # yyyy mm dd）标题下的内容
   - **总结并审视本周**：处理格式为"# [Year] 第[X]周总结"标题下的内容
3. 等待 AI 分析完成，结果将以 Callout 形式追加在被分析内容的末尾

## 日记格式要求

### 单日日记格式

```markdown
# 2026 01 26
- 工作
    - 完成了项目报告的初稿，提交给上级审阅
    - 参加了团队会议，讨论了下阶段的工作计划
- 运动
    - 跑步5公里，配速保持在6分钟/公里
    - 做了20分钟的拉伸训练
- 学习
    - 阅读了《存在与时间》的第三章
    - 学习了30分钟的法语
```

### 周总结格式

```markdown
# 2026 第4周总结
- 本周工作
    - 完成了项目的阶段性目标
    - 与客户进行了两次沟通会议
- 本周学习
    - 读完了《局外人》一书
    - 学习了新的编程技能
- 本周生活
    - 保持了规律的作息时间
    - 与朋友聚餐一次
- 下周计划
    - 完成项目的最终报告
    - 开始学习新的课程
```

## 技术原理

1. **文本提取**：使用正则表达式匹配和提取日记内容
2. **AI 分析**：调用 DeepSeek API，以加缪的哲学视角分析日记内容
3. **结果生成**：将 AI 分析结果格式化为 Obsidian Callout 并插入到日记中
